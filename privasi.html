Privasi & Data

Komitmen Euband terhadap data fisiologis kamu

🔒

Data Anda Tidak Tersimpan Permanen

Hasil sesi perekaman hanya disimpan sementara di browser selama sesi aktif. Setelah sesi diakhiri, di-refresh, atau tab ditutup, semua data fisiologis (BPM, GSR, grafik) hilang sepenuhnya. Tidak ada database, tidak ada cloud, tidak ada server yang menyimpan rekaman Anda.

Prinsip Privasi Euband

⏱
Ephemeral by Design
Data sesi hanya hidup di memori browser. Tidak ada penyimpanan permanen.
🚫
No Account
Tidak perlu daftar, login, atau memberikan identitas pribadi apa pun.
📡
Lokal & BLE
Data mengalir langsung dari device Euband ke browser via Bluetooth. Tidak melewati server.
📥
Anda Pegang Kendali
Mau simpan? Export CSV/JSON/PNG dari Dashboard. File disimpan di perangkat Anda sendiri.

Pengaturan Lokal (Browser)

Hanya satu hal yang disimpan di browser: threshold klasifikasi yang Anda atur di halaman Pengaturan. Tersimpan di localStorage browser, tidak dikirim ke mana pun.

Detail Teknis

Apa yang TIDAK kami simpan?
  • Hasil sesi perekaman (BPM, HRV, GSR, kategori, level)
  • Raw samples PPG/GSR dari device
  • Timestamp atau riwayat aktivitas
  • Identitas pengguna (email, nama, IP, device ID)
Apa yang disimpan & dimana?
  • Threshold klasifikasi — di localStorage browser Anda. Tidak dikirim ke server mana pun. Bisa dihapus kapan saja.
  • Tidak ada lainnya.
Bagaimana data sesi hilang?
  • Klik tombol "Hentikan Sesi" di Dashboard
  • Refresh halaman / tutup tab browser
  • Mulai sesi rekam baru (sesi lama otomatis ter-replace)
Bagaimana cara backup data?
  • Setelah sesi selesai, gunakan tombol ⬇ CSV / ⬇ PNG / ⬇ Report di Dashboard untuk mengunduh ke perangkat Anda
  • File hasil download adalah tanggung jawab penuh Anda — Euband tidak memiliki salinannya
