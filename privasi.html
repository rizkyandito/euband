Informasi Privasi

Data apa yang disimpan?
  • Hasil analisis tiap sesi: BPM, HRV, GSR (µS), kategori, level, durasi
  • Timestamp sesi (waktu mulai)
  • Raw samples PPG/GSR TIDAK disimpan ke cloud (hanya summary)
Dimana disimpan?
  • Database Supabase (region Singapore)
  • Mode anonymous — tidak terkait identitas user
  • Threshold setting cuma di browser kamu (localStorage)
Siapa yang bisa akses?
  • Semua user Euband bisa lihat semua sesi (mode shared pool)
  • Tidak ada akun, tidak ada login — semua anonim
